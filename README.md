# 📊 Credit Card Financial Dashboard

A comprehensive **Credit Card Financial Dashboard** developed using **Excel, PostgreSQL, and Power BI** to provide real-time insights into key business metrics and financial trends. The dashboard enables stakeholders to monitor credit card performance, analyze customer behavior, and make informed business decisions through interactive reports and KPIs.

---

# 🚀 Project Overview

This project demonstrates an end-to-end Business Intelligence workflow, beginning with raw Excel datasets and ending with interactive Power BI dashboards. The data was imported into PostgreSQL, connected to Power BI, transformed using Power Query, modeled using a Star Schema, and analyzed with DAX measures to create meaningful business insights.

# 🧹 Data Preparation

Data preparation was performed entirely in **Power Query**.

The following transformations were applied:

* Data type corrections
* Column formatting
* Data validation
* Data transformation
* Relationship preparation
* Table optimization
* Loading clean data into the Power BI model

---

# 🗄️ Database

The source data was stored in **PostgreSQL**, providing a centralized and structured database for reporting. Power BI was connected directly to PostgreSQL to ensure efficient data retrieval and analysis.

---

# 📐 Data Modeling

A **Star Schema** was implemented to improve report performance and simplify analysis.

The model consists of fact and dimension tables connected through optimized relationships, enabling efficient filtering and accurate calculations using DAX.
